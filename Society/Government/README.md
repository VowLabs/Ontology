# Government

Canonical code: `R:G`. Definition: [index.json](index.json).

Public institutions, authority, governance and civic processes.

Parent: [R](../README.md).

Applies to legislatures, public administration as an institution, elections and public policy. A particular government entity has an Identity record; public administration services remain R:SV:GV, and public financial affairs belong to B:F:PU.

This is an organizing classification, not an answer field or a claim about a subject.
It defines no answer type, units, choices or value constraints. Classification
does not establish ownership, affiliation, eligibility or verified truth.

No finer subclasses or answer fields are currently defined.
