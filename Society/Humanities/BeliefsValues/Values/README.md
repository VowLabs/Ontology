# Values

Canonical code: `R:U:BV:V`. Definition: [index.json](index.json).

Ethical principles, ideals and priorities used to guide judgment and conduct.

Parent: [R:U:BV](../README.md).

Applies to fairness, compassion, freedom and stewardship. Values concern what is important or desirable; Beliefs concern convictions and worldviews. Examples do not create enumerated values or rank cultures or people.

This is an organizing classification, not an answer field or a claim about a subject.
It defines no answer type, units, choices or value constraints. Classification
does not establish ownership, affiliation, eligibility or verified truth.

No finer subclasses or answer fields are currently defined.
