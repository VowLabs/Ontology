# Beliefs

Canonical code: `R:U:BV:B`. Definition: [index.json](index.json).

Religious or secular convictions and worldviews held by people or communities.

Parent: [R:U:BV](../README.md).

Applies to religious traditions, spiritual convictions and secular worldviews. Beliefs describe what is held to be true or meaningful; Values describe what is considered desirable or important. No truth or affiliation is asserted.

This is an organizing classification, not an answer field or a claim about a subject.
It defines no answer type, units, choices or value constraints. Classification
does not establish ownership, affiliation, eligibility or verified truth.

No finer subclasses or answer fields are currently defined.
