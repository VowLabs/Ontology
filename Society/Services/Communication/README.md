# Communication

Canonical code: `R:SV:CM`. Definition: [index.json](index.json).
Parent: [Society / Services](../README.md).

Connectivity and communication delivery supplied to people. Use this classification for a service offering or activity whose
intended customers are individuals or households, regardless of provider or
funding model. Offerings aimed at businesses belong to Business / Services
(`B:SV`).
Examples include telephone service, internet access, messaging and postal correspondence.

This describes the service used; the online account/provider definition at S:T:SV and its services dataset retain their existing purpose.

No finer classifications or answer fields are currently defined (`Children: {}`).
The examples are illustrative, not additional canonical codes. This is a service
classification, with no answer type, units or implied permission to disclose data.
