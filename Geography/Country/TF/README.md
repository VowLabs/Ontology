# French Southern and Antarctic Lands

Canonical code: `G:CO:TF`. [Definition](index.json).

This is a country or territory entry from the pinned `ekkis/geo` dataset. The
source’s common name is **French Southern and Antarctic Lands** and its official name is **Territory of the French Southern and Antarctic Lands**.
Its two-letter key is `TF` and its three-letter code is `ATF`.
These identifiers follow the source vocabulary; inclusion does not assert
sovereignty or resolve jurisdictional disputes.

Use `G:CO:TF` for a country relationship, for example as a Country choice in an
address. The country concept is distinct from a country-specific postal format.
No finer subclasses are currently imported. Capital, currency, population and
subdivision data in the upstream repository are outside this imported vocabulary.
