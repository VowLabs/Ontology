# Countries and territories

Canonical code: `G:CO`. [Definition](index.json).

This branch imports 250 country/territory identities from the pinned ekkis/geo
revision recorded in the [source manifest](../../_support/sources/index.json).
Inclusion follows the source and does not assert sovereign-state status. Each
terminal concept supplies a common name, official name, two-letter key and
three-letter code. Each has its own README and source provenance.

`"Choices": "G:CO"` constrains a country relationship to these canonical leaf
codes. A stored value such as `G:CO:US` is distinct from the display name United
States and from the US address format at `G:AD:US`.

Population, currencies, administrative subdivisions and other upstream data
are not imported as ontology datapoints in this change. Source snapshots are
retained for provenance; they do not automatically publish every upstream field.
