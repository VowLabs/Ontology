# Science

Canonical code: `S`. Definition: [index.json](index.json).

Science currently organizes Technology and Information. Technology supplies shared service metadata; Information supplies data types and information-system record classifications. These branches describe technical concepts rather than granting applications access to user data.

Parent: [NokNok ontology](../README.md).

## Subclassifications

### Technology — `S:T`

Technology currently contains the shared service registry. Registry records identify online services; the user’s own account on one of those services is modeled separately under I:C:SM.

Further classifications: Service (`S:T:SV`).

[Detailed classification guide](Technology/README.md) · [Definition](Technology/index.json).

### Information — `S:I`

Information currently specializes into Data, which separates primitive value definitions from operational record families and encrypted lexicon snapshots.

Further classifications: Data (`S:I:D`).

[Detailed classification guide](Information/README.md) · [Definition](Information/index.json).
